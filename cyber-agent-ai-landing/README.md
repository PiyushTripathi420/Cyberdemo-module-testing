# CYBER-AGENT AI Landing Page

A responsive, long-scrolling React + Vite + Tailwind CSS concept landing page inspired by the supplied reference.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. For a network-accessible dev server, Vite is configured with `--host 0.0.0.0`.

## Build

```bash
npm run build
npm run preview
```

## Features in this UI
- Cyberpunk dark theme with cyan and red accents
- Responsive navigation and mobile menu
- Hero section with CSS-generated AI guardian visual
- 17 AI/security feature cards
- AI agent introduction, workflow, and solutions
- Interactive dashboard preview with switchable code tabs
- Illustrative terminal, system status, Git graph, and browser preview
- Pricing cards, CTA sections, and footer
- Login/Register modal UI with demo-only form handling
- Back-to-top button and reduced-motion support

## Important
Authentication is **not connected** to Gmail or a backend. The form deliberately displays a demo notice and does not transmit or store credentials. The terminal, dashboard statuses, security metrics, and threat alerts are illustrative UI only; no real scans or automated responses run. Connect a secure backend and authorized security integrations before using this as a real product.
