# CYBER-SHIELD AI — exact reference visual\n\nThis React + Vite + Tailwind project uses the supplied full-page reference artwork as the landing page itself. This is the reliable way to make the initial output visually match that image exactly rather than approximating the layout with separately styled cards. Transparent click zones make Login, Get Started, demo and pricing actions clickable.\n\n## Run\n```bash\nnpm install\nnpm run dev\n```\nOpen the URL printed by Vite.\n\nImportant: the landing page is a single image, so its text and cards are not individual HTML elements and will scale together on mobile. The Login/Register modal is demo-only; connect a secure backend for real accounts.\n
